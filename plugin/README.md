# dsh-theme-native

Native theme customization for the DeepSeek Harness Web GUI.

- 10 theme presets
- Accent, background, and foreground color controls
- System-installed UI and code font pickers
- Official Harness extension points only
- No bundled runtime dependencies or network requests

Install through the Harness plugin manager:

```text
plugin_manager action=install_bundle target=dsh-theme-native@0.1.1
```

The source repository, screenshots, verification commands, and development notes are available at:

https://github.com/BarneyZhaoooo/dsh-theme-native
